01Where the work stands

The contract layer is complete: schema, domain logic, server actions, RBAC, the AI client and the audit trail. Every route that mutates data validates a strict schema, checks a capability and writes an audit event. The UI workstreams consume that contract and have not started.

The parity matrix covers all 51 nodes of the agreed use-case diagram. Each one is tied to a route or server action, so a gap is a named piece of work rather than a general feeling that something is unfinished.

02The eleven additions

Addition Tier How it is answered
Tilt / sinking indicator A Measured tilt and differential settlement, classified against 1/500 and 1/250 thresholds. Manual readings, never inferred from photos.
Crack categories A ACI 224R-01 width bands with ACI 201.1R cause, orientation and pattern. The band is computed from the measurement, not accepted from a client.
Filter A One shared, URL-synced filter bar across reports, asset vault, maintenance and dashboard.
Editable reports A Every field editable, with the previous state snapshotted into a revision table before each save.
Recommendation A AI drafts, an engineer signs. Only signed text can reach a report.
Severity scoring with cost and action A AI returns a peso range; a deterministic table computes alongside. Divergence beyond the accepted band must be confirmed by an engineer.
Structural limitation A Per-report exclusion checklist plus free text and per-element notes, printed as an explicit assessment-limitation statement.
Flood and geohazard checklists A Versioned templates prefilled from the site's actual geospatial zone membership, then confirmed or overridden.
Rebound hammer B Reading array with median ± 1.5 IQR outlier rejection, mean, and an indicative strength labelled as requiring calibration.
Soil investigation B Borehole, depth, classification, SPT N-value, groundwater and liquefaction susceptibility at site level.
Erosion B Observed condition per inspection, feeding the existing project-level erosion score rather than replacing it.
Forensic engineering B Failure hypothesis, mechanism narrative, an evidence chain linking images and detections, and a recommended next step.

03What shipped

All four UI workstreams are built and merged into staging. Migration 017 is applied to the isolated preview database, so every new screen reads and writes real rows.

Surface What is there now
Inspector · asset vault Six-panel workbench: tilt and settlement, rebound hammer, soil, erosion, forensic evidence, and flood/geohazard checklists prefilled from mapped zones.
Engineer · report route Full editing with revision snapshots, limitation statement, cost panel with divergence gate, AI-drafted recommendation with sign-off, and per-detection crack classification.
Lists and map URL-synced filters, CSV export for reports, detections and maintenance, tokenised share links, and a risk heatmap fed from recorded hotspots.
Admin · settings Audit log, counted system health, project registry with archive, record export/import with dry-run preview, and a thresholds page showing the rules in force.
Profile /profile for every role. Inspectors and engineers previously had no route to edit their own details.

04Still open

These are stated rather than hidden: a review that finds them should find them already named here.

Gap Why
Import does not carry images or detections They belong to storage objects that are not part of a record export. The UI says so before the import runs.
Heatmap is empty on a fresh site It plots recorded hotspots, not zones. No problems recorded means nothing to plot, and the panel says that instead of drawing a decorative gradient.
Rebound strength needs calibration The correlation is indicative. A site-specific curve is required before the number means what a lab number means.
Production credentials still unrotated The service-role key remains in an old handover archive and the seeded passwords sit in git history. Rotation is an owner action.
iOS build unverified No macOS host. The Android build compiles; the iOS sources have never been through Xcode.

05Rules that do not bend

main is production. Nothing reaches it without an explicit go signal. Feature branches merge into staging, and staging is what Vercel previews against an isolated database.

Provenance is recorded, not implied. Every detection says whether Gemini, the deterministic heuristic, or an engineer produced it. Live AR frames never call Gemini; only a deliberate analysis does, so a ~20 request/day quota cannot stall a scan.

Capstone depth. No model training, no payments, no multi-tenancy. Cost figures are planning-level, rebound strength needs calibration to mean anything, and the two diagram nodes beyond scope are honest equivalents rather than pretence.
